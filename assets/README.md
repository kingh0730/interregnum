# Assets

Reusable look development, shared across shots and episodes. Every keyframe prompt references these files.

- `characters/<name>/`: model sheet (front, side, back, expressions), color notes, and a `.vrm` if the character is rigged
- `locations/<name>/`: establishing painting, key angles, lighting variants
- `props/`, `style/`: props, and style frames defining each episode's visual language

Keep final, chosen images here; generate candidates in `work/` and only promote the winners.
